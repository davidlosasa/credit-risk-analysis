# Credit Risk Analysis Project

This project analyzes credit risk using three tools in a structured workflow:

- **SQL** for data preparation and processing  
- **Excel** for exploratory analysis (pivot tables and KPIs)  
- **Tableau** for interactive dashboards and visual insights  

---

##  Data Sources
- `application_record`: customer demographic and financial information  
- `credit_record`: credit payment behavior  

---

##  Workflow

### 1) Data Preparation (SQL)
- Renamed and standardized columns  
- Converted data types  
- Created new features (Age, Employment Duration, etc.)  
- Removed duplicated entries  
- Cleaned inconsistent categorical values  

### 2) Data Processing (SQL)
- Identified missing values  
- Removed useless fields  
- Prepared a final cleaned dataset for analysis  

### 3) Exploratory Analysis (Excel)
- Pivot tables to understand trends  
- Identification of anomalies and debt patterns  
- Segmentation of clients by demographics and income  

### 4) Interactive Dashboard (Tableau)
- Visual representation of results  
- KPIs for decision-making  
- Filters for dynamic exploration  

---

## Main Objectives
- Understand customer risk based on personal and financial characteristics  
- Detect behavioral patterns related to overdue payments  
- Support credit risk decisions with clear metrics and visuals  

---

##  Deliverables
- SQL scripts (preparation and processing)
- Excel file with pivot table analysis
- Tableau dashboard (interactive)
